**第三，超流量之后是限速，并非停机。** 官方文档只承诺“超出月度配额后带宽可能被限速，具体策略取决于产品规格”，服务本身仍在线直到下个计费周期。第三方整理给出的具体数值是限速到 20 KB/s，这个数字不是官方口径，但你可以按“会变得很慢、但不会直接断”来理解。

**支持 Windows 吗？** 部分套餐标注 Windows-ready，包括 HKG Turin 的 Pro 和 Ultra、HKG Pulse 的 Pro 和 Ultra。是否包含授权，官方页面没有说明，需要单独确认。

**多久能开通？** 支付完成后系统自动部署，通常几分钟内完成，IP 和登录凭据通过邮件发送。

**想换计费周期怎么办？** 公开文档里没有写这条规则的细节，直接开工单问客服最稳妥，别按猜测操作。
